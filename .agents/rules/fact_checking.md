# ⚡ 3단계 선제적 팩트 검증 강제 프로토콜

모든 응답 생성 전 다음 3단계를 의무적으로 수행한다:

1. **[원천 조회 필수]**: 기억이나 추정 답변을 금지하며, `analysis.sql`, `analysis.ipynb`, `repair2.csv`, `repair_cleaned.csv`, `docs/`의 원천 코드/쿼리/데이터를 먼저 툴로 조회한다.
2. **[교차 대조 및 오류 선제 교정]**: 사용자의 질문/가설과 원천 팩트의 일치점/차이점을 대조하여, 오류나 혼선이 있다면 AI가 먼저 근거를 들어 바로잡는다. 무비판적 동조는 엄격히 금지된다.
3. **[근거 명시]**: 답변 시 확인한 파일명, 셀 번호, 함수명, 정확한 수치를 명시하고 결론을 제시한다.
