
# Slide Design System (Reference: Pitch 'Hacker' Layout)

## 1. Concept & Tone

- Style: Tech-oriented, minimal, high data-ink ratio (Hacker template structure).
- Tone: Professional Data Analytics (Clean, sharp, structured).
- Font Hierarchy:
  - Header/Tag: Monospace font (Courier New, Consolas, or JetBrains Mono)
  - Titles & Numbers: Clean Sans-serif Bold (Pretendard, Inter, or Arial Black)
  - Body Text: Clean Sans-serif Regular (Pretendard, Arial, or Calibri)

## 2. Color Palette (Corporate Tech Dark / Light-blend)

- Background: #0D1117 (GitHub Dark / Deep Tech Navy)
- Surface/Card Box: #161B22 (카드 박스 배경)
- Border Line: #30363D (얇은 1px 테두리 - Hacker 스타일의 핵심)
- Text Primary (Title/Numbers): #F0F6FC (순수 화이트에 가까운 텍스트)
- Text Secondary (Description): #8B949E (뮤트된 그레이)
- Accent Color: #38BDF8 (Sky Blue - 핵심 지표 및 강조 인사이트용)
- Success / Warning: #2EA043 (Green) / #F85149 (Red)

*(만약 밝은 테마를 원할 경우: Background #F8FAFC, Card #FFFFFF, Border #E2E8F0, Accent #0284C7 로 스왑)*

## 3. Slide Layout Pattern (Pitch Hacker Spec)

- Top Area:
  - Tag (12pt Mono, Accent Color): e.g., `[ 02 / EDA & INSIGHT ]`
  - Action Title (24~28pt Bold): 단 1줄의 분석 핵심 결론
- Content Area (Card Grid):
  - 1px Border Box 컨테이너로 좌우 2분할(좌측 차트 60%, 우측 인사이트 40%) 또는 3분할 카드
  - Big Number는 40pt 이상으로 크게 강조하고, 바로 아래 Monospace로 지표 설명 배치
