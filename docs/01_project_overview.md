## 3. 핵심 전처리 포인트 (주의사항)
1. **타임스탬프 생성**: `date` + `time`을 결합하여 `pd.to_datetime`으로 `timestamp` 컬럼 생성 (초 단위 차이 계산용)
2. **이벤트 순서 정렬**: `caseID` 및 `timestamp` 기준으로 시간순 정렬
3. **구조적 결측치 이해**: 수리 관련 컬럼(`RepairType`, `EstimatedRepairTime` 등)은 실제 수리 task 이벤트 시점에만 생성되는 데이터이므로 단순 행 삭제가 아닌 케이스 레벨 집계(Aggregation)로 처리 필요
